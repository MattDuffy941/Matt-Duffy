# Groove Builder URL Format — Authoritative Reference

This is the **single source of truth** for the groove query-string format. It is
generated by the live web app's codec (`src/lib/urlCodec.ts`) and mirrored exactly
by the Swift port in [`GrooveCore`](GrooveCore). Do **not** infer the format from
sample URLs — use this document and the `GrooveCore` tests. If any rule here
disagrees with a guess, this document wins.

A groove is a query string. State that equals the default is omitted.

## Parameter order (exact)

```
TimeSig, Div, [Title], [Author], [Comments], Tempo, [Swing], Measures, [MetronomeFreq], H, S, K, [T1], [T2], [T3], [T4], [Stickings]
```

- `[…]` = optional, written only when non-default:
  Title/Author/Comments when non-empty; **Swing when > 0**; **MetronomeFreq when ≠ 0**;
  each `T1`–`T4` when that tom lane has any hit; `Stickings` when it has any mark.
- **Note the positions:** `Swing` is between `Tempo` and `Measures`;
  `MetronomeFreq` is between `Measures` and `H`. They are not adjacent.

## Scalar parameters

| Param | Meaning | Validation (else → default) |
|---|---|---|
| `TimeSig` | `top/bottom` | top 1–32 (else 4); bottom ∈ {2,4,8,16} (else 4) |
| `Div` | cells per whole note | ∈ {8,12,16,24,32,48} (else 16) |
| `Tempo` | BPM | 20–400 (else 80) |
| `Measures` | bar count | 1–100 (clamped) |
| `Swing` | swing % | 0–100 (clamped); written only when > 0 |
| `MetronomeFreq` | click density | ∈ {0,4,8,16} (else 0); written only when ≠ 0 |
| `Title`/`Author`/`Comments` | text | `encodeURIComponent`; `decodeMeta` also turns `+`→space |

## Lane parameters (ASCII tab, one char per grid cell)

Read left-to-right; **`|` and spaces are skipped**; **`-` is a rest**; unknown
chars are rests. `+` is a literal character (do NOT treat it as a space — this is
why the codec must not use standard form-decoding on lane values).

"emits" = the char `serialize` writes (some inputs normalise on output).

**`H` (hi-hat / cymbals):** `x`→normal · `X`→accent · `o`→open · `+`→close ·
`r`/`R`→ride (emits `r`) · `b`/`B`→rideBell (emits `b`) · `c`→crash · `s`→stacker ·
`m`→cowbell · `n`→metronomeNormal · `N`→metronomeAccent

**`S` (snare):** `o`→normal · `O`→accent · `g`→ghost · `x`→xstick · `f`→flam ·
`d`→drag · `b`/`B`→buzz (emits `b`)

**`K` (kick):** `o`→normal · `x`→splash (hi-hat foot) · `X`→kickAndSplash

**`T1`–`T4` (toms):** `o` or `x` → normal (emits `o`)

**`Stickings`:** `R`/`r`→R · `L`/`l`→L · `B`/`b`→B

### Context collisions (same letter, different meaning per lane)
- `x`: hi-hat **normal** · snare **cross-stick** · kick **foot splash**
- `o`: hi-hat **open** · but **normal** in snare/kick/toms
- `b`/`B`: hi-hat **rideBell** · snare **buzz**

## Golden verification URLs (round-trip to themselves)

Every hi-hat/snare/kick sound:
```
?TimeSig=4/4&Div=16&Tempo=80&Measures=1&H=|xXo+rbcsmnN-----|&S=|oOgxfdb---------|&K=|oxX-------------|
```

Every optional field set (locks parameter order):
```
?TimeSig=4/4&Div=16&Title=My%20Beat&Author=Matt&Comments=Hi&Tempo=100&Swing=30&Measures=2&MetronomeFreq=8&H=|----------------|----------------|&S=|----------------|----------------|&K=|----------------|----------------|
```

Toms + stickings:
```
?TimeSig=4/4&Div=16&Tempo=80&Measures=1&H=|----------------|&S=|----------------|&K=|----------------|&T1=|o---------------|&T2=|--o-------------|&T3=|----o-----------|&T4=|------o---------|&Stickings=|RLBRLB----------|
```

The Swift suite `GrooveCore/Tests/GrooveCoreTests/URLCodecTests.swift` asserts all
of the above cell-by-cell (`testExoticHitsDecodePerCell`,
`testTomsAndStickingsDecodePerCell`, `testCanonicalParameterOrder`). Run
`cd ios/GrooveCore && swift test`; green means the format is verified identical to
the website.
